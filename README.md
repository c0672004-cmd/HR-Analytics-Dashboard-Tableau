# HR Analytics Dashboard (Tableau)

An interactive, data-driven Human Resources dashboard built using **Tableau Desktop Public Edition**. This project analyzes workforce demographics, departmental distributions, salary allocations, and employee attrition trends to provide actionable insights for HR stakeholders.

## 📊 Live Dashboard
👉 [View Interactive Dashboard on Tableau Public](https://public.tableau.com/app/profile/coco.wei1646/viz/HRAnalyticsCaseStudy-WorkspaceProject/Dashboard1)

## 🔍 Key Insights Uncovered
* **Workforce Volume:** The organization is heavily anchored by the **Sales** (272 employees) and **IT** (248 employees) departments.
* **Compensation Distribution:** The **Sales** department commands the highest average salary across the company, while **HR** represents the lowest baseline.
* **Experience Density:** The majority of the workforce consists of experienced professionals, heavily peaking in the **15-year experience bin** (over 200 employees).
* **Attrition Factors:** While general retention is strong, a segment analysis indicates that **male employees exhibit a noticeably higher volume of attrition** than female employees.

## 🛠️ Dashboard Architecture & Visuals
The dashboard is designed using a clean, tiled executive grid layout consisting of six core visual sheets:
1. **Attrition by Gender** (Horizontal Bar Chart)
2. **Average Salary by Department** (Ranked Bar Chart)
3. **Experience Level Distribution** (Chronological Histogram Bins)
4. **Experience Years Overview** (Data-Labeled Pie Chart)
5. **Attrition Overview** (Segmented Stacked Bar)
6. **Department Size Tree Map** (Proportional Nested Grid)

## 🚀 How to Run locally
1. Clone this repository or download the `.twbx` Tableau workbook.
2. Open the workbook using **Tableau Desktop** or **Tableau Public**.
3. Locate the raw dataset under the `Data Source` tab if you wish to modify calculated metrics.
